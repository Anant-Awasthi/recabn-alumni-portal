# RECABN Alumni Association (RAA) Web Portal

A lightweight, serverless web application developed for Rajkiya Engineering College, Ambedkar Nagar (RECABN) Alumni Association. Designed to foster alumni engagement, streamline registration, provide a searchable verified directory, and ensure transparent governance.

## 🚀 Live Demo
- **Production URL**: [https://recabn-alumni-association.web.app/](https://recabn-alumni-association.web.app/)

## ✨ Key Features
- **Multi-Page Architecture**: High-performance, modular layout (`index.html`, `directory.html`, `opportunities.html`, `transparency.html`) optimized for fast DOM loading.
- **Searchable Alumni Directory**: Dynamic filterable interface by branch and regional chapters.
- **Opportunities & Jobs Board**: Dedicated platform for alumni to share career opportunities and referrals.
- **Financial Governance & Transparency**: Public donor recognition tiers (Bronze to Platinum) compliant with RAA Bye-Laws.
- **Responsive Mobile Navigation**: Clean, custom event-driven mobile navigation and hamburger menu logic.

## 🛠️ Tech Stack & Tools
- **Frontend**: HTML5, CSS3 (Custom Responsive Grid), JavaScript (ES6)
- **Backend / Hosting**: Google Firebase Hosting & Firestore NoSQL Database
- **Icons**: FontAwesome 6
